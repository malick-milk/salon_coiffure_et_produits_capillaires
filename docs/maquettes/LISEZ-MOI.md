# Maquettes du projet (copie du canevas)

Copie de sauvegarde du canevas de maquettes : https://claude.ai/artifact/NpExLjgNGZiUutFi51EtZL (copiée le 19 novembre 2026, 64 maquettes).
Le canevas reste la référence pour **valider** une maquette ; cette copie garde une trace dans le dépôt, même si le canevas disparaît.

| Dossier | Contenu |
|---|---|
| `apercus/` | Une image par maquette (JPEG), pour la regarder sans rien installer |
| `sources/` | Les fichiers d'origine du canevas (`*.dc.html`) et sa disposition (`canvas.json`) : de quoi tout reconstruire |
| `assets/` | Les photos et logos utilisés par les maquettes, nommés comme dans le canevas (`/_blob/<nom>`) |

**15 maquettes interactives** (carrousel, menus, onglets) ne s'affichent correctement que dans le canevas : leur source est ici, mais pas d'aperçu (marquées « canevas » ci-dessous).

Les visuels des réseaux sociaux ont aussi leur version définitive et leurs sources de travail dans `marketing/` (agent `maquettes-promo`).
